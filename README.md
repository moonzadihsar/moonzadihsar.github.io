# Rashid Anzoom — Academic Website

A responsive, single-file academic website designed for GitHub Pages. Includes research, publications, teaching, contact, and an interactive Engineering Economy time-value-of-money calculator.

## Publish on GitHub Pages (no command line)

1. Sign in at https://github.com and select **New repository**.
2. For a personal homepage, name the repository **YOUR-USERNAME.github.io** (replace `YOUR-USERNAME` with your exact GitHub username). Set visibility to **Public**.
3. Select **Add file → Upload files** and upload `index.html`, `.nojekyll`, and `README.md` from this folder; commit to `main`.
4. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. After GitHub completes the deployment, the website will be at `https://YOUR-USERNAME.github.io/`.

You may alternatively name the repository `academic-website`. Its GitHub Pages address will be `https://YOUR-USERNAME.github.io/academic-website/`.

**Important:** GitHub Pages serves public websites. Do not upload private student records or confidential research data.

## Preview / edit

Open `index.html` in a web browser. No build step is necessary. Update text directly in the HTML file and commit new changes to publish them. Verify the publications placeholder and add your headshot, CV, Scholar, and research links before promoting the site.
